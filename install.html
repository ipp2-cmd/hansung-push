아래 안내에 따라 앱을 설치해주세요

📱 Safari 브라우저에서만 설치 가능합니다
1
공유 버튼 클릭
하단 가운데 공유 버튼(⬆️)을 클릭하세요
2
홈 화면에 추가
스크롤해서 "홈 화면에 추가"를 선택하세요
3
추가 버튼 클릭
우측 상단 "추가" 버튼을 클릭하세요
4
홈화면 아이콘으로 실행
설치 완료! 홈화면의 앱 아이콘을 눌러 실행하세요 🎉
📱 Chrome 브라우저에서만 설치 가능합니다
1
메뉴 버튼 클릭
우측 상단 메뉴(⋮)를 클릭하세요
2
앱 설치 선택
"앱 설치" 또는 "홈 화면에 추가"를 선택하세요
3
설치 버튼 클릭
"설치" 버튼을 클릭하세요
4
홈화면 아이콘으로 실행
설치 완료! 홈화면의 앱 아이콘을 눌러 실행하세요 🎉
